# Media Administration UX

- Treat the left rail as the primary folder-management surface. It must expose an explicit root node, hierarchical expand/collapse, active-folder state, and contextual create/rename/delete actions following the organization-tree interaction pattern.
- Use the page-level Administration search bar for media search. Do not add a second large search field inside the workspace.
- Keep media type, sorting, and grid/list controls together in the workspace heading action area. Folder creation belongs to the folder tree, not this control group.
- Use restrained Meteor icons and compact icon containers for folders. Do not reintroduce illustrated folder thumbnails as the primary folder affordance.
- A normal media-card click must select the item and open its inspector; checkboxes remain for explicit multi-selection.
