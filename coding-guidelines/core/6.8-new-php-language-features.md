# PHP language features

## Context

Contena requires PHP 8.5 or newer and Symfony 7. Use the native language features available at that minimum instead of retaining syntax for older PHP runtimes.

Many of the new features allow us to reduce boilerplate, make it easier to prevent common mistakes, improve refactoring support, increase legibility, perform faster and so on.

By using the latest features we allow the reader and writer of code to focus on the domain rather than the language.

## Project rules

- Every class, interface, trait, and enum constant must declare its native type. Use `string`, `int`, `float`, `bool`, or `array` when the value has that type; keep PHPDoc only when it adds a narrower shape such as `list<string>`.
- Keep `Rector\Php83\Rector\ClassConst\AddTypeToConstRector` enabled so new constants with inferable values are migrated mechanically.
- Existing DAL Entity getter/setter APIs are not migrated to property hooks as part of unrelated changes. Property-hook adoption requires a dedicated change that updates DAL hydration, serialization, change tracking, callers, and tests together.
- Do not use named arguments when calling Contena APIs: parameter names are not part of the backwards compatibility promise. Named arguments are only for calling PHP APIs.

## PHP 8.4 new features

### Property hooks

* [PHP Docs](https://www.php.net/manual/en/language.oop5.property-hooks.php)
* [PHP Watch](https://php.watch/versions/8.4/property-hooks)

Property hooks replace trivial getter/setter pairs with logic attached directly to the property. Reading and writing looks like a plain property while validation, lazy initialisation or computed values live next to the declaration.

From:

```php
class NumberRange
{
    private int $start;

    public function getStart(): int
    {
        return $this->start;
    }

    public function setStart(int $start): void
    {
        if ($start < 1) {
            throw new \InvalidArgumentException('Start must be positive');
        }

        $this->start = $start;
    }
}
```

To:

```php
class NumberRange
{
    public int $start {
        set (int $value) {
            if ($value < 1) {
                throw new \InvalidArgumentException('Start must be positive');
            }

            $this->start = $value;
        }
    }
}
```

Advantages:

* Less boilerplate, the logic lives with the property.
* Callers keep plain property access syntax, migration is transparent.
* Works with interfaces and abstract properties (PHP 8.5).

#### Backwards Compatibility / Migration Strategy

See the project rules above: DAL Entity getter/setter APIs are not migrated to property hooks as part of unrelated changes.

### `new` without parentheses

* [PHP Docs](https://www.php.net/manual/en/language.oop5.basic.php#language.oop5.basic.new)
* [PHP Watch](https://php.watch/versions/8.4/new-without-parentheses)

Newly instantiated objects can be dereferenced directly, without wrapping the `new` expression in parentheses.

From:

```php
$formatted = (new \DateTime($date))->format('Y-m-d');
```

To:

```php
$formatted = new \DateTime($date)->format('Y-m-d');
```

### Asymmetric visibility

* [PHP Docs](https://www.php.net/manual/en/language.oop5.visibility.php#language.oop5.visibility-members-aviz)
* [PHP Watch](https://php.watch/versions/8.4/asymmetric-visibility)

Properties can be readable by everyone while writable only from within the class:

```php
public private(set) string $name;
```

## PHP 8.5 new features

### Pipe operator

* [PHP Docs](https://www.php.net/manual/en/language.operators.pipe.php)
* [PHP Watch](https://php.watch/versions/8.5/pipe-operator)

Chain calls left to right without nesting:

```php
$result = $value |> strtoupper(...) |> trim(...);
```

### Clone with

* [PHP Docs](https://www.php.net/manual/en/language.oop5.cloning.php#language.oop5.cloning.clone-with)
* [PHP Watch](https://php.watch/versions/8.5/clone-with)

Clone an object while overriding selected properties:

```php
$copy = clone $object with (start: 100);
```

### `#[NoDiscard]` attribute

* [PHP Watch](https://php.watch/versions/8.5/nodiscard)

Calling a function or method marked `#[NoDiscard]` while ignoring its return value raises a notice. Use it on APIs whose result must not be dropped, e.g. immutable builders.

```php
#[NoDiscard]
public function withLocale(string $locale): self
{
}
```
